JL Fitment Notes

JL (2-door) and JLU (4-door) use different rear bench sizes. Always specify door count when ordering. The JL 4XE has the same seat dimensions as the standard JL 4-door. The JL Rubicon 392 uses the same seat dimensions as the standard Rubicon JL — covers fit both. Bartact sells separate front and rear covers for the JL so you can mix configurations.
